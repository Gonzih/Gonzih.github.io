Security & Trust · CC Suite

What we do with your data,
and what we don't.

CC Suite is a set of open-source tools that bring Claude AI assistance into developer workflows. Your conversations flow through Anthropic's API under their commercial data handling terms. We don't train on your code. We don't sell your data. This page documents exactly what happens, so your compliance team doesn't have to guess.

01 — Data Handling

How your data is handled

Active

Training opt-out

CC Suite uses the Anthropic API under commercial terms. Under Anthropic's commercial API agreement, customer inputs and outputs are not used to train Anthropic's models by default. No action is needed on your end.

30 days

Data retention

Anthropic retains API inputs and outputs for up to 30 days for abuse monitoring and safety purposes, then deletes them. CC Suite itself stores nothing server-side — it is a client-side tool with no backend database.

Local only

Configuration & credentials

API keys and settings are stored locally on the developer's machine. CC Suite never transmits credentials to any server other than Anthropic's API endpoints (api.anthropic.com).

Sub-processor list

The following third parties process data in the course of using CC Suite:

  • Anthropic, Inc. LLM inference — all prompts and responses pass through api.anthropic.com. US-based. Commercial API terms apply.
  • GitHub, Inc. Source code hosting. CC Suite source code is publicly available. No user data is stored on GitHub.
  • Cloudflare, Inc. CDN and DNS for gonzih.github.io (marketing site only). No user data passes through Cloudflare.
02 — Code Transparency

Open source, fully auditable

Every component of CC Suite is published under the Apache 2.0 license. You can read, fork, and audit the full source code. There is no proprietary telemetry, no obfuscated binary, and no server-side component that handles your data.

03 — DPA & Legal

Data Processing Agreement

On request

How to request a DPA

CC Suite is currently a small open-source project. If your organization requires a formal Data Processing Agreement, contact us at gonzih@gmail.com. We will respond within 5 business days.

A DPA with CC Suite would cover: data flows between your environment and Anthropic's API, sub-processor obligations, data subject rights procedures, and breach notification. Given that CC Suite has no persistent backend, the primary DPA relationship for LLM processing is directly with Anthropic — we recommend reviewing Anthropic's Privacy Policy and their commercial API terms as the primary data processing basis.
